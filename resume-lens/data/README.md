# Real vocabulary corpus

15,068 normalized exact-text-deduplicated LEGITIMATE real EMSCAD job descriptions. Original17,880 labeled ads from University of the Aegean,2012–2014. This model fits IDF/vocabulary only; it does not learn supervised resume-match outcomes or claim ATS accuracy. Fields: title,description,requirements,benefits. HTML/entity/whitespace normalized, lowercase, max20,000 chars, legitimate rows only.
